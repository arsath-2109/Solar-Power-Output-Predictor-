# Solar Power Output Prediction Using Machine Learning

## 📌 Project Description

This project uses Machine Learning to predict solar power output based on environmental conditions such as temperature, humidity, solar irradiance, and wind speed. A Linear Regression model is trained using historical solar power data and used to predict future power generation.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Joblib
* Google Colab

## 📊 Input Features

* Temperature
* Humidity
* Solar Irradiance
* Wind Speed

## 🤖 Machine Learning Algorithm

**Linear Regression**

The dataset is divided into **80% training data and 20% testing data**.

## 📈 Model Evaluation

The model performance is evaluated using:

* Mean Squared Error (MSE)
* R² Score

Actual and predicted solar power outputs are also visualized using scatter and line plots.

## 💾 Model Saving

The trained model is saved as:

`solar_power_prediction_model.pkl`

Joblib is used to save and load the trained model for future predictions.

## 🎯 Applications

* Solar power forecasting
* Renewable energy management
* Solar plant monitoring
* Smart energy systems

## 👨‍💻 Project

Developed using Python and Google Colab for solar power output prediction using machine learning.
